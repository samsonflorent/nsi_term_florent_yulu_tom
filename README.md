Rush Hour
Présentation du projet

Rush Hour est une adaptation du célèbre jeu de réflexion et de logique du même nom.

Le principe du jeu est simple : le joueur doit déplacer différents véhicules sur une grille afin de libérer le véhicule principal et lui permettre de sortir du plateau.

Ce projet a pour objectif de reproduire les mécaniques principales du jeu original à travers une adaptation informatique.

Règles du jeu
Le plateau est composé d'une grille contenant plusieurs véhicules.
Chaque véhicule peut se déplacer uniquement dans son axe de circulation (horizontal ou vertical).
Les véhicules ne peuvent pas se chevaucher.
Le joueur doit déplacer les véhicules pour dégager le passage.
L'objectif est de permettre au véhicule principal de rejoindre la sortie.
Fonctionnalités

Cette adaptation vise à proposer une expérience de jeu fidèle au concept original de Rush Hour.

Les fonctionnalités du projet comprennent notamment :

La représentation d'un plateau de jeu.
Le déplacement des différents véhicules.
La gestion des collisions et des contraintes de déplacement.
La résolution progressive des niveaux.
